STEP 1 — INSTALL PYTHON
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to: https://www.python.org/downloads/
2. Download Python 3.10 or above
3. Install it — TICK "Add Python to PATH" during installation
4. Open Command Prompt and verify:
      python --version
   Should show:  Python 3.10.x

STEP 2 — INSTALL XAMPP (MySQL Database)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. Download XAMPP for Windows
3. Install it (default settings)
4. Open XAMPP Control Panel
5. Click START next to MySQL
6. Click START next to Apache (for phpMyAdmin)

HOW TO USE THE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. REGISTER STUDENTS:
   → Go to "Register Student" tab
   → Fill Name, Roll No, Class, Email
   → Click "Register Student"
   → Webcam opens — student looks at camera
   → 100 photos captured automatically
   → Click "Train Model" after registering all students

2. MARK ATTENDANCE:
   → Go to "Mark Attendance" tab
   → Select Subject from dropdown
   → Click "START Recognition"
   → Webcam opens — students walk in front
   → Names appear automatically — attendance marked!
   → Press Q or click STOP when done

3. VIEW REPORTS:
   → Go to "Reports" tab
   → Filter by Subject / Date Range
   → Click "Load Report"
   → Click "Export Excel" to download

4. SEND EMAIL ALERTS:
   → Go to "Email Alerts" tab
   → Select subject
   → Click "Check Low Attendance"
   → Students below 75% are listed
   → Click "Send All Alerts" to email them

COMMON ERRORS & FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Error: "Cannot connect to MySQL"
Fix:   → Open XAMPP → Start MySQL
       → Check password in config.py

Error: "No module named cv2"
Fix:   → pip install opencv-python opencv-contrib-python

Error: "Webcam not accessible"
Fix:   → Check webcam is connected
       → Close other apps using camera (Teams, Zoom etc.)

Error: "Model not found. Please train model first."
Fix:   → Register at least 1 student first
       → Then click "Train / Retrain Model"

Error: "No face detected"
Fix:   → Improve lighting in the room
       → Make sure face is directly facing the camera
