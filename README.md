# Smart-Attendance-System-Using-Face-Recognition
An automated attendance system that uses real-time face recognition to identify individuals and log their attendance, removing the need for manual roll calls.

## Features
- Real-time face detection and recognition via webcam
- Automatic attendance logging with timestamp
- SQL database storage for attendance records

## Tech Stack
- **Language:** Python
- **Computer Vision:** OpenCV
- **Database:** SQL (see `database.sql`)

## How to Run
See [`HOW_TO_RUN.txt`](./HOW_TO_RUN.txt) for setup instructions.

```bash
pip install -r requirements.txt
python main.py
```
